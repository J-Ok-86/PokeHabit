[포함된 기능]
- 오늘 추천(+10%)과 마무리 추천(+20%)을 하나의 2열 박스로 표시합니다. 각 항목은 제목/부스트 및 퀘스트 이름의 2줄이며, 둘 다 무효하면 박스 전체를 숨깁니다.
- 마무리 추천은 계정에서 설정한 마무리 브리핑 시각 이후에만 노출되고 완료 보상에 적용됩니다. 보상 계산은 추천 x1.10 이후 마무리 x1.20 단계별 반올림을 유지합니다.
- 퀘스트 목록은 기존 보라/파란 구분 배지를 유지하며 불필요한 중복 x1.32 배지는 노출하지 않습니다.
- 달력 선택 날짜의 실제 완료 목록에 기록된 오늘/마무리 부스트를 표시하고 예정/미수행 퀘스트를 보여줍니다.
- 달력과 기록 탭의 과거 퀘스트 선택 옵션을 독립적으로 유지하며 관리자 퀘스트 목록 들여쓰기를 정렬합니다.

[FINAL 검증 및 보정]
- JavaScript 구문 검사 통과: index.html / moves.html.
- 브라우저 로직 검사: 추천 시간 제한, 2개 동시 추천, 완료 후 숨김, 추천 부스트 이력 출력 확인.
- 과거 생성일을 모르는 구버전 퀘스트를 무조건 과거의 '미수행'으로 소급 표시하지 않도록 보정했습니다.
- 서비스워커 캐시 버전 변경으로 새 배포 파일을 다시 설치하도록 구성했습니다.
- 실기기 Galaxy / 실제 로그인 / GitHub Pages 배포는 이 환경에서 확인되지 않았습니다.
