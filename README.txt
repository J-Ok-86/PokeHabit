PokéRoutine v1.7.58.1 — 성도지방 열림 기준 변경 (관리자 설정)

[업데이트]
- 관동 151종 + 성도 100종 = 총 251종, 251종 상식, 지역별 도감·통계·지도 기능 유지.
- 성도지방 열림 기준 기본값: 관동의 서로 다른 포켓몬 100종 수집 (기존 76종에서 변경).
- 설정 경로: 상단 ⚙️ 설정 → 🗺️ 도감 지역 열림 기준 · 관리자 설정.
- 관리자 비밀번호 확인 후 1~151종 정수로 변경 가능.
- 이 값은 관리자 공통 규칙이며 트레이너별 독립 수집 기록에 적용.
- 한 번 열린 성도지방은 기준을 높여도 잠기지 않음. 수집 기록, 기존 훈장도 유지.
- 관동 탐험가 훈장은 성도지방 열림과 연결되고 설정값/기존 열림 상태를 반영.
- v1.7.58에서 76종 이상 수집해 성도가 이미 열려 있던 트레이너는 업데이트 후에도 이용 가능.
- 새 트레이너 / 1.7.57 이하에서 직접 업그레이드한 트레이너에는 기본 100종 기준 적용.
- 관리자 공통 규칙과 트레이너별 영구 열림 상태를 JSON 전체 백업·복원에 포함.
- 서비스워커 캐시 이름 갱신.

[적용]
1) 기존 앱에서 ⚙️ 설정 → JSON 전체 Save로 백업하세요.
2) 이 ZIP에 포함된 index.html, moves.html, sw.js를 GitHub Pages 저장소 루트에 덮어쓰세요.
3) 다른 manifest.webmanifest와 icons/ 디렉터리는 그대로 유지합니다.
4) 배포 후 앱을 새로고침하고 화면의 v1.7.58.1 표기를 확인하세요.
5) 기존 정보가 남아 있는지 확인하고 설정에서 100종 기준을 확인하세요.

[주의]
- 서버 동기화 기능은 없습니다. 브라우저/기기가 달라지면 JSON 파일로 데이터를 옮기세요.
- 기존 게임 포인트, 완료 기록, 포켓몬 목록, 훈련, 도감 설명은 변경하지 않습니다.
- 포켓몬 상식 공식 검증 상태와 갤럭시 실기기 테스트는 v1.7.58과 동일합니다.
