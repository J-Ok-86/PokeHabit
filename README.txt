PokéRoutine v1.7.25 · 나의 포켓몬 보기 옵션 & 스크롤 위치 개선

배포: ZIP 압축을 풀고 index.html, moves.html, sw.js를 기존 GitHub Pages 저장소 루트에 덮어씁니다.
README.txt는 설명용입니다. 앱의 로컬 기록은 HTML 코드 업데이트만으로 초기화되지 않습니다.

변경 내용
1. 도감 → 「이 포켓몬 트레이닝」 버튼 및 훈련 탭에서 포켓몬 선택 시
   트레이닝 조작 버튼이 아니라 「🐾 나의 포켓몬」 영역 박스의 맨 위(여백 12px)로 자동 이동합니다.
   도감에서 선택한 포켓몬 개체는 그대로 유지합니다.
2. 「나의 포켓몬」 영역 상단에 1열 / 2열 / 3열 / 4열 / 자동 보기 옵션 추가.
   기본은 2열. 자동은 화면의 실제 목록 너비에 따라 2/3/4열로 반응형 변경됩니다.
   3~4열은 그림을 중심으로 카드 정보를 더 작게 배치합니다.
3. 열 수 설정은 기기/브라우저의 localStorage에 별도로 저장되어 앱을 다시 열어도 유지됩니다.
   JSON 백업이나 계정에 동기화되지 않으며, 다른 기기에서는 별도로 선택합니다.
4. 기술 시연 위치 및 버튼, 기존 포인트·도감·레벨·계정·JSON 저장 구조는 기존 v1.7.24 유지.
5. 서비스 워커 캐시 명칭 v1725 적용.

배포 후: 앱을 새로고침하세요. 오프라인 캐시가 남아 있으면 앱을 닫았다 다시 열거나 새로고침하세요.
업데이트 전에 현재 데이터를 JSON으로 백업하기를 권장합니다.
