PokeHabit / PokeRoutine v1.7.112 — 독서 날짜별 책 타임라인

기반: v1.7.111. 독서 외 모든 퀘스트 템플릿과 기존 기록·보상, 저장 구조 그대로 유지.

주요 변경
- 독서 퀘스트 상세 분석의 '최근 구조화 기록 추세' 막대그래프를 날짜별 책 제목 타임라인으로 교체했습니다.
- 최근 7일 / 30일 버튼, 기록이 있는 날짜만 최근순 정렬, 날짜별 읽은 책 제목을 세로로 나열합니다.
- 같은 책은 여러 날짜에서도 동일한 색상의 왼쪽 선으로 식별됩니다.
- 책 이름을 누르면 기존 독서 목록 검색·해당 책 상세(시작/완독 날짜, 날짜별 구간)가 바로 열립니다.
- 템플릿 확정 기록, 작성 중 임시 기록, 과거 메모에서 추정된 책을 날짜별로 합치고 중복 제목은 하나로 표시합니다.
- 과거 메모 기반 내용은 (추정) 표시하고 완독/분량을 임의 확정하지 않습니다.
- 독서 기록이 없는 날은 생략하며 30일에 기록이 많아도 모바일에서 가로 스크롤로 확인합니다.
- 기존 책 목록, 검색, 접기/펼치기, 전체 쪽수/완독 수동 등록, 나머지 상세 분석 그래프는 그대로 유지합니다.
- 기존 '확인 구간 0쪽' 숨김 유지.

설치: index.html, moves.html, sw.js를 GitHub Pages 저장소 루트에 업로드하세요.
업데이트 전 전체 사용자 JSON 백업 필수. 개인 백업 JSON을 GitHub에 올리지 마세요.
PWA에서 변경이 보이지 않으면 새로고침 또는 완전 종료 후 다시 실행해 주세요.

PokeHabit / PokeRoutine v1.7.111 — 독서 목록의 불필요한 확인 구간 표시 제거

기반: v1.7.110, 나머지 기능과 기록 데이터 구조 변경 없음.
- 전체 독서 목록의 책별 접힌 한 줄에서 전체 쪽수가 미등록인 경우 표시되던 "확인 구간 0쪽" 및 "확인 구간 N쪽" 표시를 제거했습니다.
- 전체 쪽수가 있는 책의 진도 수치, 독서 시작/완독 날짜, 책 검색, 접기/펼치기, 날짜별 구간, (추정) 표시, 상세 분석 등 기존 기능은 그대로 유지합니다.
- 다음 책별 타임라인 디자인은 선택 전 시안만 제시하며 이번 패치에는 포함하지 않았습니다.
- 안전을 위해 업로드 전 전체 사용자 JSON 백업을 보관하세요.

PokeHabit / PokeRoutine v1.7.110 — 전체 독서 목록 검색 · 접기/펼치기 · 독서 날짜와 구간 이력

기반: v1.7.109. 기존 퀘스트, 완료 이력, 메모, 보상, 독서/운동/학습 템플릿 및 데이터는 유지합니다.

이번 v1.7.110 개선
- 전체 독서 목록은 책 한 권당 한 줄 요약으로 표시합니다. 각 줄을 누르면 상세 정보가 열리고, 다시 누르면 접힙니다.
- 전체 독서 목록의 제목 검색으로 등록된 책 및 과거 메모에서 찾은 미등록 책을 함께 찾아볼 수 있습니다. 검색어 지우기 시 전체 목록이 다시 표시됩니다.
- 등록된 책과 과거 메모에서 찾은 책 모두 날짜별 읽은 구간을 표시합니다. 같은 날 여러 구간을 읽었으면 날짜 아래에 모두 표시합니다.
- 확정 완료 기록 / 완료 전 중간 저장(작성 중) / 기존 메모에서 추정된 구간(추정)을 구분합니다.
- 독서 시작일은 사용자가 직접 입력할 수 있습니다. 입력하지 않았다면 첫 독서 기록 날짜를 표시하며 과거 메모에서 유추한 경우 '(추정)'을 붙입니다.
- 완독 여부는 사용자 직접 체크 정책 유지. 완독일은 기본적으로 체크한 날짜로 기록하며 책 수정에서 날짜를 변경할 수 있습니다.
- 기존 메모의 '완독' 언급은 (추정·미확정)으로만 표시하고 실제 완독 상태를 변경하지 않습니다.
- 독서 퀘스트의 '템플릿 상세 분석'에서도 한 줄 접기/펼치기, 날짜별 독서 구간을 제공합니다. 전체 책 검색은 '책 검색 · 목록 관리'로 진입합니다.
- 기존 기록 메모, 달성량, 포인트, 경험치, 완료 상태는 변경하지 않습니다. 책 정보(startedOn, finishedOn)는 계정별 JSON 백업/복원에 보존됩니다.

기존 v1.7.107 ~ v1.7.109 기능도 유지
- 퀘스트별 템플릿 선택/미리보기, 여러 책 입력과 책 제목 자동완성, 수동 전체 쪽수 등록 및 완독 체크
- 운동 세트별 자동 입력 시각 및 중간 저장, 템플릿별 누적량·추세·정답률·페이스·볼륨 분석
- 과거 메모의 책 제목·쪽수 구간을 (추정)으로만 분석하고 원본은 유지

설치: 기존 GitHub Pages 루트에 ZIP의 index.html, moves.html, sw.js를 교체해 업로드합니다.
사전 필수: 현재 앱의 '전체 사용자 JSON 백업'을 별도 안전한 장소에 보관하세요. 개인 JSON 파일을 공개 GitHub에 올리지 마세요.
