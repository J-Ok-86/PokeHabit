PokéRoutine v1.7.119 — 운동 세트 기록 그래프 일별 누적 영역·축 개선

업데이트 방법
1. 앱에서 전체 사용자 JSON 백업을 먼저 보관하세요.
2. ZIP 내 index.html, moves.html, sw.js를 GitHub Pages 저장소에 덮어씁니다.
3. 반영 이후 앱 헤더가 v1.7.119로 바뀌었는지 확인하세요.

변경 사항
- 운동/근력 운동 분석을 일별 세트 횟수 순위라는 동일 기준으로 통일
- 7일: 일별 세트별 누적 막대 (각 세트의 횟수와 일별 총횟수)
- 30일·90일: 색상별 세트 순위를 날짜 사이로 연결한 일별 누적 영역 그래프
- 90일은 주별 최고 세트 요약을 제거하고 90일 동안의 실제 일별 총 반복 횟수·세트 분포로 표시
- X축은 모든 기간 월/일(MM/DD)이며 30·90일은 간격을 줄여 필요한 눈금만 표시
- Y축은 '회' 단위의 정수 눈금으로 표시
- 30/90일 전체 그래프를 눌러 해당 일자의 7일 상세 누적 막대로 확대
- 기록이 없는 날은 0회로 처리하되, 일반적인 과거 기록을 구조화 세트 수로 추정해 섞지 않음
- 세트 크기별 색상은 매일 내림차순 순위; 같은 색이 날짜를 건너 동일 세트인 것은 아님

변경하지 않은 기능
- 기존 실제 달성량 그래프, 독서 타임라인, 생활 리듬 분석, 운동 세트별 시간, 기타 퀘스트 기록
- 보상/포인트/경험치/기존 데이터·JSON 저장 구조

검증
- JavaScript 구문 검사
- 실제 기록과 형식이 같은 샘플을 이용한 7/30/90일 종목별 집계, 중량 필터, 차트 선택 동작
- 320/360/390/430/760px X축 날짜 충돌·가로 넘침 검사(초기 누적 차트 버전)
- 누적 영역 연결 모양은 브라우저 분리 시안으로 시각 확인
- 실제 Galaxy PWA 전 기능 통합 테스트는 별도 필요
