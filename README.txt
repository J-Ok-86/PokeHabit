PokeRoutine v1.7.102 — 주간 수면 리듬 & 월요일 기상 체크 14점 비율 보상

1. 달력 → 라이프이벤트 아래에 주간 수면 리듬이 표시됩니다. 월~일 저녁 취침과 각 다음 날 아침 기상을 7쌍으로 연결합니다.
   - 각 행에 두 실제 시각, 취침/기상 각 성공·실패·미기록·예정 상태가 표시됩니다.
   - ✓ 초록: 하루 두 개 모두 성공 / △ 주황: 둘 중 하나만 성공 / ✕ 빨강: 측정했으나 성공이 없음 / — 회색: 미기록 / · 회색: 앞으로의 기록
   - '이전 주 / 이번 주 / 다음 주' 버튼으로 날짜를 탐색할 수 있습니다.

2. 월~일 '22:00 이전 취침 7회 + 다음 날 08:00 이전 기상 7회' 총 14개 목표를 독립 평가합니다.
   - 달성률은 성공 횟수/14입니다. 7/7일 모두 두 목표에 성공하면 14/14 · '완벽 달성'을 표시합니다.
   - 14/14 최대 기본 보상은 포인트 1,000P와 경험치 500XP입니다. 비율 보상은 각각 Math.round(최대값×성공 횟수/14)로 계산됩니다.
   - 예: 13/14 -> 929P / 464XP, 12/14 -> 857P / 429XP.
   - 점수 0이라도 완료 주차로 기록되고, 같은 주 보상을 중복 지급하지 않습니다.

3. 평가·지급 시점은 고정 시각이나 앱 실행이 아닙니다.
   - 다음 월요일에 사용자 본인의 기존 '🌅 기상' 라이프이벤트를 실제로 저장할 때만 지난 한 주의 결과를 확정하고 보상을 지급합니다.
   - 이 버튼이 전날 일요일 취침을 마감하는 마지막 아침 기록입니다. 평가 후 수정·삭제해도 해당 주 지급은 변동되지 않습니다.
   - 월요일 이외의 입력, 앱 실행·복귀, 소급 입력은 지급을 발생시키지 않습니다.
   - 신규 업데이트 도입 전 과거 주차에 대한 자동 소급 지급은 없습니다.

4. 관리자 → 운영 설정 → 포인트·XP → '수면 리듬 주간 보상'에서 14/14 기준 최대 포인트와 경험치를 변경할 수 있습니다.
   - 개인별 주간 보상은 해당 계정 기록에 저장되고 JSON 백업·복원에 포함됩니다.
   - 경험치 지급은 기존 레벨업·경험치 이월 계산을 사용합니다. 피버 배수 미적용.

5. GitHub Pages 배포: 데이터 JSON 백업 후 ZIP에 포함된 index.html / moves.html / sw.js를 기존과 동일한 경로에 업로드해 덮어쓰세요.
   이 패키지에는 사용자 데이터/비밀번호가 들어 있지 않습니다.
