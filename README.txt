PokéRoutine v1.7.99 — 하루 돌아보기 (기존 기록 기반 자동 회고)

기준: v1.7.98 (하루 타임로그 확대·좌우 이동 포함)

핵심 기능
- 달력 탭에서 날짜 선택 → 날짜 이력 제목 아래 '✨ 하루 돌아보기' 버튼 → 자동 회고 패널.
- 선택한 트레이너의 해당 날짜 완료 퀘스트, 실제 달성량, 순간 기록, 라이프 이벤트, 데일리 노트만 조회.
- 상단: 3종 기록 건수 및 기록된 첫/마지막 시각. 시각은 지속 시간을 의미하지 않음.
- '측정된 성과'에 실제 달성량이 입력된 퀘스트 최대 4건 표시. 원본 클릭 시 기존 퀘스트 완료 상세를 펼침.
- '최근 생각'에 마지막 순간 기록 2건 미리보기. 클릭 시 기존 순간 기록 상세로 이동.
- 데일리 노트는 최대 170자 미리보기만 제공하며 원문/작성은 기존 데일리 노트로 이동.
- '이전 기록 / 다음 기록'은 실제 기록이 있는 날짜만 오가는 탐색. 닫으면 원래 달력으로 복귀.
- '회고 복사'는 클릭 시에만 기존 원문을 로컬 클립보드로 복사. 자동 복사가 제한되면 선택 가능한 텍스트 표시.

중복 방지/확장성
- 신규 저장 필드, 중복된 기록, 보상 수정, 자동 AI 분석, 계정 간 공유, 외부 API 호출 없음.
- 데이터 집계 dailyRecapSnapshot() / recorded day index dailyRecapDates() / 텍스트 출력 dailyRecapCopyText()를 UI와 분리해 향후 주간·월간 회고에서 재사용할 수 있게 구성.
- 달력 퀘스트 필터가 걸려 있어도 회고는 전체 퀘스트 집계. 퀘스트 원문 이동 시 해당 날짜 전체 퀘스트로 전환.
- 날짜 이동 시 현재 선택 계정의 기록만 사용. 원본 수정·삭제 시 다음에 회고를 열면 즉시 재계산.
- 기존 타임로그 확대/드래그, 기록 탭의 퀘스트별 전체 이력, 노트 모아보기 검색을 보존.

적용
1. 설정에서 기존 데이터 JSON 백업 (주의: 계정 비밀번호 등이 포함되므로 공개 저장소에 업로드 금지).
2. 이 ZIP 안 index.html, moves.html, sw.js를 GitHub Pages 저장소의 같은 이름 파일에 덮어쓰기.
3. GitHub Pages 배포 완료 후 PWA를 완전히 종료하고 다시 실행. 구버전 화면이 계속 보이면 새로고침.
4. 달력에서 2026-11-18 등 기록이 있는 날짜 선택 → 하루 돌아보기 확인.

검증
- 사용자 백업의 계정별 스키마(완료, 순간생각, 생활기록, 데일리노트)와 연결 확인.
- JavaScript 문법 검사, v1.7.99 UI의 320px 모바일 시뮬레이션 렌더링, 소스 변경/기록 저장 필드 회귀 검사.
- 실제 Galaxy PWA 및 전체 OS 조합 검증은 수행하지 않았음.

배포 ZIP에는 개인 백업 JSON이 포함되지 않음.
