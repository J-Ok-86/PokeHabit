PokeHabit / PokeRoutine v1.7.106 — 오늘 탭 컴팩트 추천·순간생각 링크 개선

기준: v1.7.105. 기존 사용자 기록·포인트·퀘스트·수면 보상·다른 화면을 유지합니다.

수정 사항
1) 오늘 탭 상단 연속 도전 / 오늘 완료의 공간 축소, 퀘스트 추천을 오른쪽으로 배치
   - 화면 너비가 아주 좁은 경우에는 읽기 쉽게 추천이 아래로 내려갑니다.
   - 추천이 없을 때 상태 두 카드가 나머지 폭을 사용합니다.
2) 기존 '✎ 기록'을 '💭 순간생각 기록' 링크로 강조
   - 클릭 기능 그대로: 달력의 기존 순간 기록 입력 위치로 이동
   - 새로운 기록창/데이터 형식 없이 기존 momentLogs 사용
3) 오늘 추천은 장기 미수행과 최근 수행률, 최근 추천 후 미수행 기록을 균형 있게 반영
4) 마무리 추천은 진행 중인 타이머, 완료 전 기록, 최근 수행 빈도를 우선 고려
   - 기본 마무리 시간(21:00) 이후에만 나타나며 설정 시각을 그대로 존중
5) 추천 이유 한 줄, 추천 항목 터치 시 기존 퀘스트 카드로 이동 및 접힌 상세 열기
6) 오늘 추천/마무리 추천이 같은 퀘스트일 때 카드는 하나로 표시
   - 포인트/경험치 보너스 적용 순서는 기존 그대로 +10% 다음 +20%
7) 추천 선정 이력은 계정별 recommendationHistory 필드에 최대 180건 보존
   - 이전 JSON 호환, 최신 JSON 백업·복원 지원
   - 하루에 이미 선정된 퀘스트는 변경하지 않으며, 완료한 추천은 숨김
