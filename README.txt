PokéRoutine v1.7.96 — 수행 리듬 미수행 표시 개선

V1.7.95를 기반으로 적용한 변경 사항
- 기록 탭 > 퀘스트별 성장 리포트 > 수행 리듬에서 미수행 예정일을 빨간색으로 표시합니다.
- 완료는 초록색, 일부 완료는 노란색, 예정 없음·오늘 미확정은 중립색을 유지합니다.
- 일별 미수행 표시는 빨간색 ×, 주간·월간 미수행은 빨간색 0%입니다.
- 7일·30일·90일·1년 보기에 같은 판정 기준을 적용하며 통계 계산·보상·기존 기록 데이터는 변경하지 않았습니다.

V1.7.95에서 이미 제공되는 기능
- 달력 날짜 상세에서 기상, 출근, 업무 시작, 운동, 취침을 원터치로 기록합니다.
- 버튼 3~6개 표시, 나머지 '더보기'; ON/OFF, 이름, 이모지, 색상, 순서, 참고 시각, 1회/반복 기록 방식 설정.
- 오늘은 누른 시각으로 바로 기록하고 되돌릴 수 있습니다. 과거 날짜는 시각을 입력해 기록합니다.
- 기록의 날짜·시간·메모 수정 및 삭제. 하루 1회 이벤트의 중복 기록 방지.
- 하루 타임로그에 기존 퀘스트·순간 기록과 구분된 라이프 이벤트 표시줄과 목록 추가.
- 기록 탭에 실제 저장 기록을 바탕으로 한 최근 7일 생활 리듬 분석과 시각 추이 추가.
- 사용자별 독립 저장. JSON Save/Load와 계정별 데이터 내보내기/가져오기에 필드 포함.

유의 사항
- 앱 사용 패턴만으로 기상·취침을 추정하거나 확정하지 않습니다.
- 라이프 이벤트는 퀘스트가 아니므로 보상, 포인트, XP에 영향을 주지 않습니다.
- 취침/기상 시각 간의 시간차는 실제 수면시간이 아닙니다.
- 자동 저장 OFF 사용 시 JSON 백업이 필요합니다.

업데이트 방법
1) 앱 설정 탭에서 최신 데이터를 JSON으로 먼저 백업합니다.
2) 이 ZIP의 index.html, moves.html, sw.js를 기존 GitHub 저장소에 덮어씁니다.
3) GitHub Pages 업데이트가 완료되면 PWA를 완전히 닫았다 다시 실행합니다.

브라우저 테스트: 320px 화면에서 원터치 생성/수정/반복, 커스터마이징, 표시 개수, 더보기, 통계 확인 완료.
실제 Android/Galaxy PWA 구동은 별도 기기 확인이 필요합니다.
