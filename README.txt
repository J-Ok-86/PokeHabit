PokeRoutine v1.7.116 — 생활 리듬 전체 흐름·반복 이벤트 수행 시각 개선

업데이트 방법
1. 전체 사용자 JSON을 백업합니다.
2. ZIP의 index.html, moves.html, sw.js를 기존 GitHub Pages 저장소에 덮어씁니다.
3. 게시 후 새로고침 또는 PWA 재실행으로 v1.7.116을 확인합니다.

주요 변경
• 기록 탭 > 생활 리듬 분석 > 전체 흐름: 단순한 전체 기록 건수·평균 횟수·기록량 7일 표를 삭제.
• 최근 7일간 실제 1회형 이벤트 기록 시각을 일별 비교 표로 표시합니다.
• 사용자는 최대 4개의 1회형 이벤트를 선택할 수 있습니다(계정별 JSON 백업 보존).
• 선택한 분석 기간(7/30/90일)의 이벤트별 평균 시각·시각 변동폭을 표시합니다.
• 반복형 이벤트는 이벤트 분석에서 기록 횟수 차트 외에 최근 7일 개별 수행 시각을 표시합니다.
• 30/90일 보기에서는 오래된 기록이 있는 날짜를 더 보기로 펼칠 수 있습니다.
• 시각 버튼을 누르면 기존 원본 시각/메모 편집 화면으로 이동합니다.
• 기존 모든 기록, 단위, 퀘스트·보상·책 목록 및 다른 분석 기능은 유지됩니다.

표시 주의
• 날짜 칸의 — 는 앱에 기록이 없다는 뜻이지 실제로 수행하지 않았다는 뜻이 아닙니다.
• 취침 기록은 밤 기준 날짜에 표시하고 새벽 취침은 전날 밤에 연결합니다.
• 전체 흐름 표는 최근 7일로 고정, 표 아래 평균 시각/변동폭은 선택 기간 7/30/90일 기준입니다.

검증
• JavaScript 구문 확인.
• 컴포넌트 브라우저 320/360/390/430/760px 가로 넘침 없이 동작.
• 전체 흐름 이벤트 선택, 7·30·90일 전환, 개별 시각 버튼 원본 연결, 과거 내역 펼침 확인.
• 전체 앱 화면에서의 Android PWA 통합 시험은 별도 필요.
