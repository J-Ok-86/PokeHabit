PokeHabit Web v1.7.137 · Compact Sleep Estimate UI

PokeRoutine_v1.7.136에서 달력 탭의 APK 전용 기상·취침 추정 표시만 간결하게 변경한 버전입니다.
GitHub Pages 저장소 루트에 index.html, moves.html, sw.js를 덮어쓰세요.

- 추정 항목당 한 줄: 월/일 시각 · 기상/취침 추정 · [확정]
- 추정 신뢰도, 미사용 시간, 안내 장문 등 화면 점유 요소 삭제 (내부 추정 로직은 유지)
- 수동 기록이 있는 항목은 확정 버튼과 해당 줄 숨김. 모두 기록되었으면 영역도 숨김.
- '확정'을 누르기 전에는 기존 기록/통계에 반영하지 않음.
- 기존 사용이력 기반 추정 로직과 개인별 시간 보정은 변경하지 않음.
- PWA에서는 추정 영역을 표시하지 않음. 기존 수동 라이프 이벤트 기능 유지.
- HTML/JS, Android 프로젝트 구조에는 다른 변경 없음. APK는 다시 빌드할 필요 없음 (웹 UI 업데이트).

주의: 새벽에 실제로 기상하여 장시간 활동 후 재취침한 경우는 현 추정 알고리즘이 확실하게 구별하지 못합니다. 현재 알고리즘은 짧은 새벽 사용 클러스터(최대 20분) 1개를 고려하며, 과거 수동 기록과 후보 시각의 차이를 중앙값으로 보정합니다. 이번 ZIP은 알고리즘이 아닌 UI 패치입니다.
