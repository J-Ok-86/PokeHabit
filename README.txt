PokéRoutine v1.7.74 — 하루 타임로그 · 순간 기록

• 달력 날짜 선택 시 하루 타임로그를 표시합니다. 퀘스트가 승인 완료된 시각과 직접 작성한 순간 기록의 시각을 24시간 축에 각각 점으로 표시합니다.
• 퀘스트 시작 시간, 종료 시간, 소요 시간은 새로 측정하지 않습니다. 기존 완료 기록의 at 값(승인 시각)을 이용하며, 기록이 없는 과거 퀘스트는 시각 없음으로 표시합니다.
• 순간 기록은 오늘 날짜에서 작성합니다. 유형(생각·일상·아이디어), 기분, 한 줄 메모를 입력하면 작성 시각이 자동 저장됩니다. 수정·삭제 가능하며 수정해도 원래 시각을 유지합니다.
• 달력 날짜에 💭 마크, 월별 순간 기록 건수, 계정별 기록 저장, JSON Save/Load 및 계정별 병합 기능을 지원합니다.
• 오늘 화면의 '💭 순간 기록' 버튼에서 달력 작성 위치로 이동할 수 있습니다.
• 기존 V1.7.73 행운 상자 위치 동작, 보상 계산 및 모든 퀘스트 기능은 유지합니다.
