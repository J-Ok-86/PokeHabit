PokéRoutine v1.7.97 — 퀘스트별 전체 수행 기록

기준: v1.7.96

추가된 기능
- 기록 탭 → 퀘스트별 성장 분석에서 특정 퀘스트 선택 → 그래프 아래 '📚 전체 수행 기록'을 펼쳐 조회.
- 기본은 접힘. 펼치면 모든 날짜의 완료 기록을 최신순 30건부터 표시하고, '30건 더 보기'로 이전 기록을 계속 볼 수 있습니다.
- 날짜·메모·달성량 검색, 전체/30일/90일/1년 기간 필터, 메모 있는 기록만 보기, 최신순/오래된순 정렬.
- 각 항목도 기본 접힘: 완료일·시각·달성량·포인트를 간단히 표시; 펼치면 목표·XP·메모·기록 수정·날짜 상세 이동.
- 같은 날 동일 퀘스트를 여러 번 완료한 경우에도 클릭한 기록을 정확히 수정하도록 연결.
- 숫자 미입력과 실제 0을 구분합니다. 다른 단위는 합산하지 않습니다.
- 퀘스트 기록이 오래되어도 기존 완료 이력은 그대로 보존. 별도의 복제 데이터를 만들지 않고 사용자별 완료 기록을 읽습니다.
- 완료 보상 재지급, XP 변경, 기존 기록 삭제 없이 조회 및 기록 내용 수정만 허용합니다.

적용 방법
1) 앱 설정 탭에서 현재 데이터를 JSON으로 먼저 백업합니다.
2) ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소에 덮어씁니다.
3) 배포 후 설치형 PWA를 완전히 닫았다 다시 실행합니다.

검증 범위
- JavaScript 문법 검사 통과.
- 320px 브라우저에서 기본 접힘, 30건 더 보기, 검색, 메모 필터, 기간 필터, 개별 펼침 테스트.
- 동일 날짜의 여러 완료 기록을 서로 구분하는 편집 대상 선택 로직 확인.
- 390px/768px 전체 앱 및 갤럭시 PWA 실기기 검증은 완료하지 못했습니다.
