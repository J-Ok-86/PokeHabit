PokéRoutine v1.7.35 · 좌우 스와이프 탭 이동 옵션 추가 (v1.7.34 기반)

- 오늘 → 뽑기 → 도감 → 훈련 → 달력 → 기록: 화면에서 한 손가락으로 좌우 스와이프 시 인접 탭 이동
- 설정 → 👆 좌우 스와이프로 탭 이동: ON/OFF, 기본 ON, 기기별 브라우저 설정으로 저장
- 세로 스크롤, 슬라이더·텍스트 입력, 가로 스크롤 영역, 도감 두 손가락 확대와 충돌 방지
- 로그인, 관리자·설정·트레이너 비교 화면 및 모든 팝업은 스와이프 탭 전환 비활성화
- 가장 첫 번째/마지막 탭은 순환하지 않음; 기존 탭 버튼 이동은 그대로 유지
- 기존 훈장, 트레이닝, 격언/명언 192개, 사용자 데이터 및 JSON 구조 변경 없음
