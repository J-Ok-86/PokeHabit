PokéRoutine V1.7.68 — 한줄 리스트 완료 상태 표시 개선

V1.7.67 기반 GitHub Pages 업데이트입니다.

변경 사항
- 한줄 리스트: 퀘스트 이모지/이름 앞에 상태 네모박스를 표시합니다.
- 미완료: 빈 네모박스, 옅은 붉은 배경, 왼쪽 붉은 상태선
- 완료: 체크된 녹색 네모박스, 옅은 초록 배경, 왼쪽 초록 상태선
- 기존 추천 배지/연속 수행/수행률 오른쪽 위치/펼치기·완료 버튼은 그대로 유지합니다.
- 상태 네모박스는 표시 전용으로, 완료 처리는 기존 완료 버튼을 통해 진행합니다.
- 다른 퀘스트 보기, 데이터 저장 및 보상 계산은 변경하지 않습니다.

적용 방법
1. 앱의 전체 JSON 데이터를 먼저 백업합니다.
2. ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소에 덮어씁니다.
3. 새로고침 후 V1.7.68 표시를 확인합니다.

검증 범위: JavaScript 구문, 상태 마크업 위치, 분리 화면(320/390/800px) 확인. 실제 갤럭시 PWA 통합 검증은 별도입니다.
