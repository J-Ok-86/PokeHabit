- 관리자 → 일반 훈장 달성 기준: 6개 분야 × 5개 등급 기준 사용자 지정
- 기존 획득 훈장 여부 무시: 저장된 모든 계정의 실제 누적 기록으로 현재 등급 재판정
- 기준 미달 훈장은 회수, 전시 슬롯 자동 해제, 특별 훈장 자격도 재판정

- 모든 포켓몬/포인트/경험치/퀘스트 기록 보존
- 오늘의 격언은 화면 너비와 문구 실제 길이에 맞춰 글꼴 크기를 자동 조정하여 항상 한 줄 유지
- 짧은 격언은 큰 글자 유지, 좁은 화면의 긴 격언만 축소 (줄바꿈/말줄임표 없음)
