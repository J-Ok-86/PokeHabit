PokéRoutine V1.7.91 | 오늘 탭 날씨 통합 (V1.7.90 기반)

업데이트 파일: index.html, moves.html, sw.js

추가된 기능
- 오늘 탭의 기존 상단 시계 오른쪽에 작은 날씨 아이콘과 현재 기온 표시. 별도의 높이를 추가하지 않으며 다른 탭에서는 날씨 아이콘을 숨깁니다.
- 아이콘 탭 시 현재 날씨, 체감온도, 앞으로 12시간의 시간대별 기온/날씨/강수확률, 습도, 풍속을 보여주는 팝업.
- 팝업의 '↻ 새로고침'으로 즉시 최신 날씨 조회를 시도합니다.
- 앱 새로고침 시 이미 위치 권한이 허용되어 있거나 수동 지역을 설정한 경우 자동으로 새 예보를 조회합니다.
- 화면을 다시 활성화하면 약 20분이 지난 예보는 자동 갱신을 시도합니다.
- 위치 권한이 없을 때는 팝업에서 '📍 현재 위치'를 눌러 허용하거나 '⌕ 지역 검색'으로 국내 도시를 직접 선택할 수 있습니다.
- 오프라인이나 API 오류 시 마지막 정상 응답(최대 24시간)을 표시하되 최신 예보가 아님을 표시합니다.
- 데이터 출처: https://open-meteo.com/ (예보 API 및 Geocoding API). 인터넷 연결이 필요합니다.

개인정보 및 데이터
- GPS 좌표는 앱의 퀘스트 기록/JSON 백업에 저장하지 않으며, 이후 갱신할 때 위치 권한으로 다시 조회합니다.
- 수동 선택한 도시의 이름/좌표와 예보 캐시만 이 기기의 localStorage에 따로 저장합니다.
- 퀘스트 데이터·경험치·포인트·보상·훈련·기존 뒤로 가기 경로는 변경하지 않았습니다.

테스트
- 320/390/768px Chromium에서 팝업, 국내 도시 검색 결과 선택, 시간별 12개 예보, 업데이트, 닫기, 탭 변경, 자바스크립트 오류 검사를 진행했습니다.
- 네트워크 응답은 테스트용 API 모킹 데이터입니다. 실제 날씨 데이터 값은 조회하지 않았고, 갤럭시 설치형 PWA GPS 권한 흐름은 실제 기기에서 추가 확인이 필요합니다.
