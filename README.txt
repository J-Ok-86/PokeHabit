[이번 변경]
1) 퀘스트 관리 > 등록/수정: 달성 기록 유형 (사용 안 함 / 메모 / 숫자+단위+메모), 기본 단위를 선택합니다.
2) 퀘스트 완료 승인: 달성량(선택), 단위, 컨디션, 최대 500자 상세 메모를 기록합니다. 입력하지 않아도 완료됩니다.
3) 달력 날짜 선택 > 완료 목록: 당시 달성량/메모/컨디션 및 추천 부스트/기록 보너스 배지 확인, 기록 수정 가능.
4) 기록 탭 > 퀘스트 성장 리포트 > 해당 퀘스트 선택: 7/30/90/365일 기준 실제 달성량 시각화.
   - 단위별 집계/선택, 누적/최고/기록당 평균/기록 횟수, 최근 수치, 컨디션 분포.
   - 기간별 합계 그래프, 초반 vs 최근 기록 평균 비교(해당 단위 4건 이상).
   - 현재 설정 목표의 숫자·단위가 기록 단위와 일치하면 최근 실적 대비 목표 달성률 표시.
   - 기록이 없는 기간은 '—', 실제 0회 입력은 '0'으로 표시합니다.
   - 기록하지 않은 날은 평균에서 제외하고, 서로 다른 단위를 섞어 합산하지 않습니다.
   - 목표 변경 시 과거 기록에 새 목표를 소급 적용하지 않습니다.
5) 설정 > 달성 기록 상세 작성 보너스: 기본 OFF, 관리자 PIN 인증 후 ON/OFF 전환(전체 트레이너 공통).
   - 완료 승인 시 상세 메모 공백 제외 10자 이상 + ON이면 그때 산정한 포인트·XP에 +20%를 각각 추가 지급합니다.
   - 숫자만 작성하거나 짧은 메모는 추가 보너스를 받지 않습니다.
   - 지급은 한 번만 확정됩니다. 사후 기록 수정으로 보너스 추가 지급/회수는 하지 않습니다.
6) 기록은 기존 JSON Save / Load / 병합에 보존되며, 레거시 기록에 존재하지 않는 수치는 만들어내지 않습니다.
7) 푸시 알림 / 주간 N회 퀘스트 기능은 추가하지 않았습니다.
