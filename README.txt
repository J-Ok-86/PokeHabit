- 걷기를 기본 라이프 이벤트로 추가: 시작/종료 원터치, 이전 시작·종료 시각과 완료 횟수 표시. 기존 이벤트 동작 보존.

- Android 기상·취침 사용 공백 추정: 신뢰도/추정 명시, 확정 클릭 후에만 기존 기록으로 저장. PWA 자동 추정 화면 숨김.
