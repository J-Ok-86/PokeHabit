PokeRoutine v1.7.115 — 시작·완독 날짜 점 연결 + 컴팩트 타임라인

적용 방법:
  압축 안의 index.html, moves.html, sw.js를 기존 GitHub Pages 저장소에 업로드해 덮어씁니다.
  기존 데이터를 지우지 마세요. 적용 전 JSON 전체 백업을 권장합니다.

변경 사항:
  • 독서 시작/첫 기록 날짜는 실제 날짜 점 위, 완독일은 실제 날짜 점 아래에 표시
  • 각각의 날짜와 점은 짧은 세로 연결선으로 이어짐
  • 양 끝 날짜의 라벨은 영역 안쪽으로 펼쳐져 잘리지 않음
  • 같은/인접 날짜의 시작 및 완독도 상하 서로 다른 줄을 사용해 겹치지 않음
  • 행 높이를 줄여 보다 많은 책이 화면에 표시됨
  • 7일/30일 보기, 기간 이동 스와이프, 상하 페이지 스크롤, 책 상세/검색, 추정 표시 유지
  • 저장 구조·보상·기타 퀘스트 분석은 변경하지 않음

브라우저(특히 Android PWA)에서 전체 복원/조작 테스트 권장.
