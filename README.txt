PokéRoutine v1.7.29 · 오늘 탭 미니 훈장 명찰 업데이트

배포: 압축을 풀고 index.html, moves.html, sw.js를 GitHub PokeHabit 저장소의 기존 경로에 덮어쓰세요. 새로 설치할 때는 기존 아이콘과 manifest 파일을 유지하세요. 배포 전 JSON 전체 백업을 권장합니다.

주요 변경 사항
- 오늘 탭의 대형 훈장 전시대를 제거하고 TODAY'S ADVENTURE 제목 오른쪽에 독립된 [🏆 전체 훈장함] 버튼 배치.
- 이름 옆에 대표 훈장 1개(조금 크게), 추가 획득 훈장 최대 2개, 나머지 +N 표시. 획득이 없다면 회색 잠금 1개만 표시.
- 훈장 획득 현황 0~10개 / 영구 부스트 / 48시간 한정 부스트를 한 줄로 요약. 매분 잔여시간 갱신.
- 훈장함에서 획득한 일반 또는 특별 훈장을 선택해 [오늘 탭 대표 훈장으로 지정] 가능. 선택은 트레이너별 데이터에 저장되고 JSON 백업·복원에 포함.
- 기존 훈장 달성 조건, 승급, 보상 및 부스트 계산, 도감·훈련 이동과 기존 기록은 유지.
- 모바일 화면과 라이트/다크 테마의 반응형 레이아웃 적용.

GitHub Pages 자동 배포는 이 ZIP으로 이뤄지지 않습니다.
