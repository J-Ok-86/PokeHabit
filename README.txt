PokéRoutine V1.7.90 · 실제 달성량 날짜축과 포인트 선택 개선

- V1.7.89 기반. 실제 달성량 그래프에서 날짜와 실제 측정 점이 동일한 X좌표를 사용합니다.
- 주요 눈금은 실측 기록이 존재하는 실제 날짜에서 선택하며, 가로·세로 보조선을 정렬해 그립니다.
- 각 점은 누르거나 키보드로 선택할 수 있습니다. 해당 날짜의 달성량 합계, 기록 건수, 여러 기록의 개별 값을 표시합니다.
- 같은 날짜의 여러 완료는 1개의 점으로 합산합니다. 이동평균은 값이 기록된 최근 7일의 합계 평균이며, 측정 없는 날짜는 0으로 채우지 않습니다.
- 기본 통계의 회당 평균 및 분석 메시지는 이전 버전처럼 개별 완료 기록 기준으로 유지됩니다.
- Android 휴대폰/탭을 위한 점 크기, 날짜 라벨 크기, 선택 포커스 가시성을 개선했습니다.

적용: 설정에서 JSON 백업 후 ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소 루트에 덮어쓰세요.

PokéRoutine V1.7.89 · 달력/기록 탭 통합 개선 (GitHub Pages 업데이트)

[수정 출발점]
- V1.7.88 기반. 기존 계정 데이터/보상 계산/훈련/종료 처리 보존.

[달력 탭]
1. 상단 퀘스트 선택을 한 줄 드롭다운 + 전체 유형 보기 체크로 단순화.
2. 월간 요약 5개 수치 → 완료 횟수, 활동일, 반복 퀘스트 달성률 3개.
3. 날짜별 예약은 한 줄 표시(건수 및 +예약), 예약된 항목은 별도 펼치기.
4. 날짜별 보상 요약은 한 줄로 축소; 시간축·퀘스트/순간 기록 상세와 중복 최소화.
5. 포획·이벤트·카테고리/퀘스트 변경·보너스는 '기타 활동 N건' 기본 접힘으로 통합.
6. 연간 요약은 월별 완료 횟수 대신 반복 퀘스트 예정 대비 달성률/완료-예정 수 및 진척 막대 표시.
7. 이력의 예정 정보는 과거 날짜의 검증 가능한 범위만 계산; 오늘 진행 중·미래 날짜는 달성률 분모에서 제외.

[기록 탭]
1. 상단 기간은 퀘스트 분석용임을 명시. 주간 브리핑은 별도의 '어제까지 종료된 7일 대 이전 7일' 공정 비교.
2. 분석 대상 퀘스트 선택도 한 줄 드롭다운으로 단순화하며 일회성/이벤트 포함 전체 유형 표시 지원.
3. 90일/365일 수행 리듬 타일에 주별/월별 달성률 % 표시(예정 없음은 구분).
4. 실제 달성량 X축은 기록 순서가 아닌 실제 날짜 간격. 동일일 다중 기록은 같은 X좌표.
5. 실측값·7회 이동평균·현재 목표 참고선 유지, 목표 변경 과거 소급 해석 금지.
6. 데이터 수와 목표 충족·변동성·추세에 따른 실천 제안 추가.
7. 노트/순간 기록 모아보기 바로가기는 성장 분석 아래로 이동.

[변경하지 않음]
- 기존 퀘스트·보상·포획 확률·개별 기록 수정·JSON 저장 구조·계정별 데이터.
- JSON 백업/복원 및 자동 저장은 설정 탭에서 계속 관리.
- 달력 날짜별 하루 타임로그와 시간축, 메모의 실제 원본 데이터.

[적용]
1. 현재 앱의 JSON 데이터 백업을 권장합니다.
2. ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소 루트에 덮어씁니다.
3. 배포 후 갤럭시 PWA를 완전히 닫고 재실행해 새 버전을 확인합니다.

[검증 범위]
- JavaScript 문법 검사 및 압축파일 무결성 검사.
- Chromium 모바일/태블릿 320px, 390px, 768px 화면 예시 데이터 렌더링.
- 월간 3지표, 예약 접힘, 기타 활동 접힘, 12개 연간 월별 달성률 카드,
  기록 그래프/이동평균/조회 기간/가로 넘침 여부 검증.
- 실제 사용자의 JSON 데이터와 실물 갤럭시 PWA 기기 검증은 수행하지 않음.
