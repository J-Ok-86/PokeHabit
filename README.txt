PokéRoutine V1.7.66 — 오늘 탭 수행률 오른쪽 정렬 및 빠른 이력 달력

V1.7.65를 기반으로 한 GitHub Pages 업데이트 파일입니다.

변경 사항
- 격자 카드의 수행률 배치는 유지
- 리스트 / 간단 리스트 / 한줄 리스트의 수행률을 각 행 오른쪽 끝에 정렬
- 퀘스트명이 길거나 연속 수행·추천·완료 표시가 있어도 수행률 오른쪽 정렬 유지
- 수행률을 누르면 해당 퀘스트의 월별 수행 이력 달력 팝업 바로 표시
- 월 이동, 날짜별 완료·예정 미수행·임시 기록 구분, 최근 완료 6건과 상세 기록 표시
- 팝업에서 나와도 오늘 탭과 퀘스트 펼침 상태 유지
- 기존 포인트·경험치·포획·저장 데이터 구조 및 수행률 정렬 방식 변경 없음

설치
1. 반드시 PokéRoutine에서 전체 JSON 백업을 따로 저장하세요.
2. ZIP을 풀어 index.html, moves.html, sw.js 를 GitHub Pages 저장소 루트에 덮어씁니다.
3. GitHub Pages 배포 후 새로고침하고 상단 v1.7.66 표시를 확인하세요.

검증
- Chromium의 실제 앱 코드로 320 / 390 / 800px 리스트 3종의 오른쪽 정렬과 가로 넘침 점검
- 길고 짧은 퀘스트명·완료/미완료 상태 혼합 테스트
- 수행률 누름 → 달력 팝업 / 이전 달 이동 / 최근 완료 기록 / 닫기
- 간단 및 한줄 리스트에서 팝업 누를 때 상세 항목이 펼쳐지지 않는지 확인
- JavaScript 구문 / ZIP 무결성 검사
- 실제 갤럭시 설치형 PWA에서는 별도 확인 필요
