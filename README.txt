PokéRoutine v1.7.118 — 운동 세트별 누적 막대 분석

업데이트 방법
1. 기존 앱의 전체 사용자 JSON 백업을 먼저 보관하세요.
2. 이 ZIP에 포함된 index.html / moves.html / sw.js를 GitHub Pages 저장소에 덮어씁니다.
3. 게시 후 새로고침하거나 PWA를 다시 열어 v1.7.118 표시를 확인하세요.

변경 사항
- 운동·근력 운동의 구조화 세트 분석을 일별 '누적 세트 막대'로 전환
- 가장 횟수가 많은 세트가 아래, 세트별 색상과 숫자(공간 허용 시), 막대 위 일별 총 횟수
- 7일: 하루 1개 막대, 읽을 수 있는 크기로 세트별 수치 표기
- 30일: 날짜 30개 전체의 작은 색상별 막대 + 선택한 7일을 크게 확대
- 90일: 13개 주간 최고 세트 요약 막대 + 선택한 주의 7일 세트 구성 확대
- 막대/주간 막대를 눌러 확대 기간 변경, 7일 확대에서 날짜 선택 시 정확한 세트별 횟수·시각 표시
- 근력 운동은 중량 필터 유지, 과거 일반 기록은 (추정) 별도 유지
- 운동 외 분석·실제 달성량·원본 기록·포인트·경험치·JSON 포맷 변경 없음

검증
- JavaScript 구문 확인, 320/360/390/430/760px 모바일·태블릿 화면 넘침 확인
- 7/30/90일 기간 전환, 일/주 선택, 종목·중량 전환, 집계값 계산 확인
- 실제 Galaxy PWA 전체 통합 시험은 별도 필요
