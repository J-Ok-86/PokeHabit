PokeHabit / PokeRoutine v1.7.104 — 생활 리듬 분석 개편
====================================================

기준 버전: v1.7.103 (기존 기능 및 보상 설정 유지)

변경 내용
1. 기록 탭의 '생활 리듬 분석'을 이벤트 유형에 따라 구분
   - 하루 1회: 각 날짜의 대표 시각(첫 기록) → 시각 추세, 평균 시각, 시각 변동폭, 목표 대비 비교
   - 여러 번: 모든 이벤트 기록 → 일별 횟수 막대, 전체 기록 횟수, 기록일 평균, 오전/오후/저녁·야간 분포
   - 이력이 없는 날은 1회형에서 미기록(선 연결 없음), 반복형에서 0회로 명확히 표시
2. 동일 카드 내 '전체 흐름 / 이벤트 분석' 전환, 7일·30일·90일 기간 선택
   - 7일·30일: 일별 시각/횟수
   - 90일: 주별 대표 시각/주간 합계(일별 반복 목표선은 표시하지 않음)
   - 7일 요약 미니 보드 유지; 날짜 터치로 기존 달력의 라이프이벤트 기록에 이동
3. 라이프이벤트별 목표를 생활 리듬 분석에서 설정·해제
   - 1회형: HH:MM 이전 목표 시각, 반복형: 일일 횟수 목표(1~99회)
   - 기존 이벤트 설정의 '참고 시각'과 새 '목표 시각'은 별개
   - 목표 미설정 시 성공/실패를 임의로 판정하지 않음
   - 목표 수정 시 과거 기록의 현재 기준 비교 표시가 바뀔 수 있지만 원본과 지급 보상은 바뀌지 않음
4. 수면 리듬 7열 체커는 그대로 유지; 표 아래 '현재 성공·예상 보상' 중복 줄만 삭제
   - 위쪽 달성률·보상 요약, 범례, 7열, 월요일 기상 체크 정산 정책은 유지
5. 라이트/다크 테마, 320px~1200px 반응형, 사용자별 기록·설정과 JSON 백업/복원 지원

데이터 구조
- 기존 lifeEventConfig, lifeEventLogs 기록 원본은 변경하지 않습니다.
- 새 선택값 lifeRhythmView: eventId / days / panel
- 새 목표값 lifeRhythmGoals: 이벤트별 time / count
- 두 필드 모두 트레이너별 데이터로 저장·복원됩니다.
- 수면 주간 리뷰, 경험치, 포인트, 수면 보상 관리자 설정은 변경하지 않습니다.

배포 방법
1) 앱에서 전체 JSON 백업을 먼저 받아 안전한 곳에 보관합니다.
   주의: JSON에는 사용자 인증 정보가 들어갈 수 있으므로 공개 GitHub에 업로드하지 마세요.
2) 이 ZIP의 index.html / moves.html / sw.js를 PokeHabit GitHub Pages 저장소의
   기존 동일 경로 파일과 교체합니다.
3) 배포 후 앱이 이전 버전을 표시하면 새로고침한 뒤 버전 v1.7.104를 확인하세요.

- 실제 v1.7.103 JSON 백업 읽기/정규화/재저장 시 기록 수·포인트·경험치 보존 확인
