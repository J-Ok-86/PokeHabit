- 미획득은 색을 제거한 잠금 실루엣 유지. 일반 훈장 슬롯에 누적 실적/다음 등급 요구량 표시.

- 전체 훈장함에도 각 일반 훈장의 현재 등급/현재 실적/다음 목표 설명 표시.
- 등급별 기본 달성 기준은 변경하지 않음. 48시간 일반 부스트, 특별 영구 부스트 및 퀘스트 보상 계산은 v1.7.27과 동일.
- 모든 개인 기록/도감/퀘스트/기존 훈장 데이터 저장 구조 유지.
