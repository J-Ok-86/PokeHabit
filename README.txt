PokéRoutine V1.7.93 | 모든 탭 공통 상단 날씨 표시
(V1.7.92 기반 · 기존 데이터/보상/날씨 API 연결 유지)

변경 사항
- 날씨 아이콘 + 기온을 시계와 동일한 고정 상단바에 모든 로그인 탭에서 표시.
- 오늘 / 뽑기 / 도감 / 훈련 / 달력 / 기록 / 설정 / 관리자 화면에서 동일한 위치.
- 탭 전환 시 날씨 DOM이 재생성되지 않고, 이전 조회 결과가 유지됨.
- 모든 탭에서 날씨 아이콘을 누르면 기존 시간별 날씨 팝업을 열 수 있음.
- 로그아웃/잠금 화면에서는 날짜·시간과 같이 상단 날씨도 숨김.
- 날씨 아이콘 무테 디자인 및 V1.7.92의 재시도·캐시 기능 유지.
- PWA 서비스워커 캐시 버전 갱신.

설치: 기존 JSON 데이터를 백업한 후 index.html, moves.html, sw.js를 GitHub 저장소에 덮어쓰고 배포하십시오.
실기기 PWA 업데이트 후 이전 화면이 남는 경우 앱을 완전히 종료하고 다시 실행해 새 캐시가 활성화되었는지 확인하십시오.

PokéRoutine V1.7.92 | 날씨 시간 초과 대응 및 상단 아이콘 디자인 정리
(V1.7.91 기반 · 기존 퀘스트/보상/저장 구조 유지)

수정한 내용
- 오늘 탭 시계 옆의 날씨 아이콘과 기온을 둘러싸던 테두리, 버튼 배경, 둥근 모서리 제거.
- 날씨 최초 조회 시 사용자가 아이콘을 직접 누르면 GPS 권한 요청 가능 (기존에는 이미 위치 권한을 가진 경우만 자동 조회).
- Open-Meteo의 예보 요청 연결이 실패/시간 초과되면 MET Norway 기상 예보 API에 자동으로 한 번 대체 조회.
- 조회 중 GPS/기본 API/대체 API 단계를 구분해서 표시하고, 두 제공처 모두 실패하면 오류 원인을 알림.
- 마지막 정상 날씨 캐시는 실패 시 삭제하지 않음. 대체 API의 예보는 제공처 운영 정책에 맞게 최대 3시간 재사용.
- 시간별 예보 12개, 지역 검색, 수동 새로고침은 유지. 대체 소스에서 체감온도 자료가 없으면 '정보 없음'으로 표시.
- 날씨 캐시와 수동 지역 설정 키는 이전 버전과 동일하게 유지. 데이터나 보상, 퀘스트 설정은 변경하지 않음.

사용법
1. 기존 포켓루틴의 설정에서 JSON 백업을 받아 두세요.
2. 이 ZIP의 index.html, moves.html, sw.js 파일을 GitHub Pages 저장소에 덮어쓰세요.
3. 배포 완료 후 PWA를 완전히 닫고 다시 실행하세요. 캐시된 구버전 화면이면 앱을 재시작하세요.
4. 오늘 탭 시계 옆 날씨 아이콘을 누르고 위치 권한을 허용하세요. GPS 시간이 초과되면 '지역 검색'에서 지역을 선택하세요.
5. 예보가 오래되면 팝업의 '새로고침'을 누르세요. 네트워크 차단 시에는 마지막 정상 예보를 볼 수 있습니다.

기술 참고
- 기본 제공처: Open-Meteo https://open-meteo.com/
- 대체 제공처: MET Norway https://api.met.no/
- 지역 검색: Open-Meteo Geocoding https://geocoding-api.open-meteo.com/
- 연결 2곳이 모두 실패한다면 Wi-Fi/모바일 데이터의 DNS·방화벽 차단 가능성이 있습니다.
- 위치 좌표는 포켓루틴 JSON 백업에 포함되지 않습니다. 브라우저 위치 권한 요청은 HTTPS 환경에서 필요합니다.

테스트 범위
- JS 문법 검사 완료.
- Chromium 모의 API 테스트에서 기본 API 실패→MET Norway 대체 성공, 기본 API 성공, 모두 실패 시 기존 정상 예보 보존 확인.
- 390px 브라우저 화면에서 weather chip CSS의 border 0px / 투명 배경 / 모서리 0px 확인.
- 실제 갤럭시 기기 네트워크와 GPS, 두 외부 API 실시간 연결은 이 환경에서 검증할 수 없었습니다.
