PokéRoutine v1.7.100 — 하루 돌아보기 전체 표시 개선
기준: v1.7.99 (타임로그 확대·기록 모아보기·기존 회고 포함)

변경사항
- 하루 돌아보기의 '측정된 성과' 수량 제한(4건) 제거: 해당 날짜에 숫자로 측정한 모든 완료 기록 표시.
- 각 성과의 이름, 완료 시각, 측정 수치·단위, 상세 메모를 생략하지 않고 표시.
- '최근 생각 2건' 제한 제거: 해당 날짜 순간생각 전부 시간순, 원문 줄바꿈 포함해 표시.
- 데일리 노트 170자 제한 제거, 작성한 원문 전체 표시.
- 원문 이동 기능 유지하되, 전체 카드 클릭이 아니라 작은 '원본 기록' 버튼으로 분리해 회고 화면에서 텍스트 선택·복사 가능.
- 휴대폰 1열, 태블릿/데스크톱 넓은 화면의 2열(성과 + 생각) 레이아웃, 긴 텍스트 자동 줄바꿈, 스크롤 가능한 모달 및 하단 고정 버튼.
- 화면상 모든 기록은 선택한 트레이너·선택한 날짜의 기존 백업 데이터에서 읽기만 함. 신규 저장 스키마·별도 DB·외부 API 사용 없음.
- 기존 타임로그 확대·드래그, 퀘스트 기록 상세, 날짜 이동, 복사, JSON 백업·복원, 계정 분리 유지.

설치
1. 현재 PokeHabit에서 개인정보가 포함된 JSON을 별도 안전한 곳에 백업.
2. 이 ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소의 같은 이름 파일로 교체.
3. 배포 후 앱 다시 열기. 업데이트가 반영되지 않으면 PWA를 완전히 종료한 다음 열고 새로고침.
4. 달력 → 원하는 날짜 → ✨ 하루 돌아보기에서 전체 성과/생각을 확인.

참고
- 날짜별 모든 생각을 보여주며, 다른 날짜의 생각을 포함하지 않음. 날짜 탐색 버튼을 이용하면 그날 기록을 볼 수 있음.
- 달성량이 없는 퀘스트는 측정된 성과에 표시하지 않음. 전체 완료 횟수는 상단 지표 및 타임로그에 표시.
- 성과가 많거나 내용이 길면 회고 창 안에서 세로 스크롤.
- JSON 파일의 계정 비밀번호 등이 노출되지 않도록 공개 저장소에는 업로드 금지.
- 실제 다양한 기기에서 동작을 절대 보장할 수는 없으며 브라우저 화면 모의검증을 수행.
