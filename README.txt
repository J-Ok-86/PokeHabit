PokéRoutine v1.7.34 · 매시간 바뀌는 한국어·영어 격언/명언 확대

- 기존 한국어 격언 24개 유지 + 한국어 격언 72개 + 영어 격언/명언 96개 = 총 192개
- 각 트레이너별 고정 셔플, 한국어·영어 번갈아 1시간마다 새로운 문구 (기기 현지 시각의 매시 정각)
- 192시간(8일) 동안 같은 문구 반복 없이 순환, 같은 시간 새로고침해도 동일
- 앱이 켜져 있어도 매시간 자동 변경; 다른 탭에서 오늘 탭으로 복귀해도 현재 시간의 문구 표시
- 오늘 탭의 격언은 기존의 한 줄 자동 글자 크기 조절 기능 유지
- 기존 훈장, 부스트, 관리자 설정, 포켓몬, 퀘스트 및 저장 데이터 변경 없음
