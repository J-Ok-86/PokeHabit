PokéRoutine v1.7.38 · 캘린더 예약·데일리 노트·대표 포켓몬 하루 브리핑

업데이트 요약
- 달력 날짜에 📅 예약 퀘스트 표시. 예약 기간에는 마크, 연속 테두리 및 건수 표시. 날짜를 누르면 예약명·기간·완료 여부 확인.
- 퀘스트명/기간(시작~종료)/선택 목표만 입력하는 간편 예약. 📅 예약 카테고리, 기본 포인트/XP, 10분 챌린지 자동 적용. 예약 생성·수정은 기존처럼 관리자 PIN 필요.
- 지정 기간 동안 매일 오늘 탭에 나타나며, 종료 후에는 활동기록 보존.
- 달력 완료율을 0% + 초록색 5단계(1~20/21~40/41~60/61~80/81~100%)로 변경. 예약 마크는 별도로 표시.
- 달력에 노트 모아보기 버튼, 날짜/내용 검색 및 목록에서 직접 수정·저장.
- 오늘 탭 대표 포켓몬의 오전 계획·저녁 마무리 브리핑: 하루 한 번 자동 표시, 다시보기 버튼 제공. 기존 매일 반복 팝업 체크는 제거.
- 오전: 예약 일정 우선, 오늘 진행률과 퀘스트별 연속 수행·마지막 수행일 표시.
- 저녁: 완료 퀘스트, P/XP 실적, 미완료 퀘스트, 오래 쉬었던 퀘스트 1개 +20% 야간 추천 보너스, 당일 데일리 노트 작성.
- 설정에서 저녁 마무리 브리핑 시각 변경 가능(기본 21:00).
- 달력 퀘스트 선택은 현재 퀘스트만 기본 표시. '과거 퀘스트도 표시' 토글을 켜면 이전 이력 확인 가능. 영구 삭제/별도 휴지통 기능 없음.
- 계정별 일정, 기록, 노트, 저녁 시각, 브리핑 확인 상태, 추천 내역이 JSON 백업/복원에 포함.
- 기존 훈장/XP/도감/포켓몬 트레이닝/레벨업/격언 등 기능 유지.

적용 방법
1. 사용 중인 앱에서 먼저 JSON Save로 백업하세요.
2. GitHub 저장소 PokeHabit 루트의 index.html, moves.html, sw.js를 이 ZIP 파일의 동일한 세 파일로 교체하세요.
3. GitHub Pages 반영 후 앱을 새로 열거나 새로고침하세요. 캐시가 남으면 앱을 완전히 종료 후 다시 열어주세요.
4. 앱은 브라우저 로컬저장소를 이용하며 서로 다른 브라우저/기기 사이 자동 동기화는 지원하지 않습니다.

검증
- JavaScript 문법 및 독립 로직 테스트: 예약 날짜 판정, JSON 변환, 날짜 마킹, 달력 달성률, 오전/저녁 1회 표시, 다시보기, 예약 생성·수정, 노트 직접 수정, 야간 추천 +20% 지급 및 보상 단계.
- 전체 모바일 브라우저 시각 테스트는 실행 환경 제한으로 완료하지 못했습니다. 실제 기기에서 확인해 주세요.
