PokéRoutine v1.7.26 · 선택된 포켓몬 상세 카드 위치 보정

GitHub Pages 업데이트: ZIP 압축을 푼 뒤 index.html, moves.html, sw.js를 저장소 루트에 덮어씁니다.
README.txt는 설명용이며, 코드 교체로 데이터가 초기화되지는 않습니다. 업데이트 전 JSON 백업을 권장합니다.

변경 사항
1. 도감 → 「이 포켓몬 트레이닝」 버튼을 누르면 선택된 개체를 유지한 채 훈련 탭으로 이동하고
   「선택된 포켓몬 상세·트레이닝 카드」의 상단 테두리부터 표시합니다 (여백 16px).
2. 훈련 탭의 「나의 포켓몬」 목록에서 개체를 고를 때에도 동일하게 상세 카드 상단으로 이동합니다.
   따라서 포켓몬 이미지, 이름, 레벨, 경험치, 트레이닝 버튼이 있는 카드가 바로 나타납니다.
3. 「나의 포켓몬 목록」 1/2/3/4열/자동 보기 기능과 기기별 보기 저장은 기존대로 유지합니다.
   열 수 설정을 변경할 때만 목록 영역으로 스크롤합니다.
4. 기존 포켓몬 데이터, 포인트, 기술 시연 UI, 퀘스트, 계정, JSON 백업 구조는 변경하지 않았습니다.
5. 서비스 워커 캐시 명칭 v1726으로 갱신했습니다.

참고: 모바일 앱 캐시가 남으면 앱을 새로고침하거나 재실행하여 변경 사항을 반영하세요.
