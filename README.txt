PokéRoutine V1.7.71 — 대결 결과 중복 메시지 정리

V1.7.70을 기준으로 대결 결과 화면의 표시만 개선한 GitHub Pages 업데이트입니다.

수정 내용
- 승리 후 포획 성공: 결과 메시지 1개만 표시합니다. 포켓몬 정보 카드와 도감 버튼은 유지합니다.
- 승리했지만 포켓볼 실패: 탈출·도주 결과 메시지 1개만 표시합니다.
- 대결 패배: 내 대표 포켓몬이 헤롱거리고 야생 포켓몬이 도망가는 결과 메시지 1개만 표시합니다.
- 대결 진행 중에는 단계별 안내 1개만 표시하며, 기존의 제목·강조 박스·결과 설명 중복을 제거했습니다.
- 결과 화면에서는 이미 끝난 기술 교환 안내와 승률 설명을 숨겨 정보를 간결하게 했습니다.
- 공격/방어/타격/포켓볼 애니메이션, 승리 시 +20%p 최대 99% 포획 확률, 데이터 저장·복원, 보상/도감/진화 구조는 그대로입니다.

적용 방법
1. 기존 JSON 백업을 저장합니다.
2. ZIP의 index.html, moves.html, sw.js를 기존 GitHub Pages 저장소의 동일한 위치에 덮어씁니다.
3. 앱을 완전히 닫고 다시 열어 V1.7.71 버전을 확인합니다.

테스트
- JavaScript 구문 및 ZIP 무결성 점검
- 결과 분기별 메시지 중복 여부 확인
- 브라우저 화면의 결과 레이아웃 및 작은 화면 오버플로 점검

갤럭시 PWA 실기기 테스트는 별도로 필요합니다.
