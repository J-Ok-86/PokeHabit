PokeRoutine v1.7.103 — 기록 탭 7열 수면 리듬 보드

업데이트:
- 기록 탭 > 생활 리듬 분석 바로 아래에 수면 리듬을 배치합니다. 달력 상세에서는 중복된 수면 주간 표를 제거합니다.
- 가로 7열로 취침 시각, 기상 시각, 기록상 수면 간격, 달성 결과를 비교합니다. 좁은 모바일에서도 좌우 스크롤 없이 표시합니다.
- 각 열은 '기상한 날짜'를 기준으로 합니다. 지급 대상 주간은 월요일 밤~일요일 밤 총 7박이므로, 화면 열은 '화 수 목 금 토 일 월'로 표시합니다.
- 마지막 월요일 열의 취침은 전날 일요일 밤 취침을 의미합니다. 월요일 새벽 01:00에 입력한 취침도 일요일 밤에 연결하고 +1을 표시합니다. 목표가 22:00이면 취침 미달성입니다.
- 월요일 새벽 01:00과 같은 월요일 밤 21:50은 수면 회차가 다르므로 두 기록을 별개로 저장할 수 있게 기존 라이프 이벤트 하루 1회 판정을 보완합니다.
- 수면 간격은 취침 버튼 기록 시각부터 다음 날 기상 버튼 기록 시각까지의 간격입니다. 실제 수면 시간을 측정한 값이 아닙니다.
- 섹션 내 '설정' 버튼을 눌러 개인별 취침/기상 목표를 편집합니다. 목표는 오늘 밤부터 시작하는 다음 수면 회차에 적용되며 과거 기록/정산 보상은 소급 변경되지 않습니다. 목표 변경 이력은 JSON 백업/복원에 저장됩니다.
- 기존 매주 월요일 '기상' 버튼 체크 때 한 주 취침 7+기상 7 총 14점에 비례하여 관리자 설정 보상(기본 1,000P/500XP)을 한 차례 지급하는 정책을 유지합니다.
- 기존 정산 주차별 기록을 보존하고 같은 주에 중복 지급하지 않습니다. 관리자 보상 설정은 변경하지 않았습니다.
