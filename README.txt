PokéRoutine V1.7.69 — 야생 포켓몬 레벨·대결·5마리 진화·도감 보유 수량

V1.7.68을 기반으로 한 GitHub Pages 업데이트입니다.

주요 변경 사항
1. 야생 포켓몬 Lv.1~30 등장: Lv.1 80%, Lv.2~9 15%, Lv.10~19 4%, Lv.20~30 1% (트레이닝 레벨 상한 준수)
2. Lv.10 이상 야생 포켓몬은 대표 포켓몬이 지정되어 있으면 특별 대결을 진행합니다. 서로 기술을 한 번씩 사용하며, 승률은 레벨·기술 위력·타입에 따라 20~90%로 계산합니다.
3. 대결에 이기면 별도 포획 주사위 없이 포획하며, 야생 레벨이 유지됩니다. 대표 포켓몬이 없으면 기존 포획 방식이 적용됩니다.
4. 동일 종류 5마리로 진화: 남길 개체 1마리를 선택하고 나머지 4마리를 사용합니다. 대표 포켓몬은 자동 재료 사용을 금지합니다. 기존 레벨 진화 유지.
5. 도감 카드 오른쪽 위에 현재 보유한 같은 종류가 2마리 이상일 때 ×2, ×3 등 작은 수량 배지가 나타납니다. 한 마리 이하 또는 미발견 포켓몬은 숨깁니다.
   이 수량은 누적 포획 횟수가 아니라 현재 보유한 개체 수를 기준으로 하므로 5마리 진화 후 자동으로 바뀝니다.
6. 기존 지역/도감/퀘스트/달성 기록과 JSON 백업·복원 형식 유지. 새로 추가한 전투 이력 및 진화 관련 데이터의 복원 로직 포함.

적용 방법
1. 현재 앱에서 JSON 전체 백업을 만든 뒤 파일을 따로 보관합니다.
2. 이 ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소의 동일한 위치에 덮어씁니다.
3. 배포가 끝나면 앱을 다시 열어 V1.7.69 버전을 확인합니다. PWA 캐시가 남으면 앱을 완전히 종료 후 다시 실행합니다.

검증
- JavaScript 구문·ZIP 무결성
- 높은 레벨 분포 경계, 특별 대결 표시 및 대결 결과 복원
- 동일 종류 5마리 진화, 남긴 개체 레벨/XP·대표 상태 유지, 4마리 사용
- 도감 중복 수량 표시/숨김 및 진화 후 자동 반영
- 도감 카드·목록 320/390/800px 화면 가로 넘침 점검

실제 갤럭시 PWA 실기기 및 장기간 사용 환경에서는 추가 검증이 필요합니다.
