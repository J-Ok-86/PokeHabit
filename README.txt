PokéRoutine v1.7.101 — 하루 돌아보기 시간순 통합
기준: v1.7.100 완전 회고 버전

변경 사항
- 퀘스트 완료(측정 성과뿐 아니라 모든 완료), 순간생각, 라이프이벤트를 시간순 하나의 세로 타임라인으로 표시.
- 라이프이벤트 이모지·시각·이름·메모, 퀘스트 제목·완료 시각·달성량·메모, 순간생각 원문 전부 표시.
- 새벽/오전/오후/저녁 시간대로 묶고 같은 시각의 여러 기록도 각각 독립된 항목으로 모두 표시.
- 시각이 없는 기록은 목록 마지막 '미기록' 구간, 시각 정보 없는 데일리노트는 마지막 별도 영역.
- 회고 복사도 전체 시간순으로 변경. 원본 이동과 기존 달력 타임로그 확대·드래그 보존.
- 기존 JSON 데이터와 로그인 계정 분리 유지. 신규 저장 필드 없음.
- 모바일과 데스크톱 모두 한 줄 시간 흐름을 유지하도록 반응형 세로 타임라인 사용.

설치
현재 JSON을 별도로 백업한 후 index.html, moves.html, sw.js를 GitHub Pages의 같은 이름 파일로 교체하세요.
모바일 PWA에서 이전 파일이 계속 보이면 앱을 다시 열고 새로고침 하세요.
개인정보가 포함된 JSON은 공개 저장소에 업로드하면 안 됩니다.
