PokéRoutine V1.7.59 — 기록 탭 그래프 전면 개선

[이번 버전 핵심]
- 기존 V1.7.58.2를 기반으로 퀘스트 및 포켓몬, 지역 지도, 상식, 보상 기능 유지.
- 기록 탭의 최근 7일 완료, 퀘스트 수행/포인트/XP, 연속 수행일, 실제 달성량 그래프를 통일된 반응형 차트로 교체.
- X축 날짜 및 일·주·월 집계, Y축 눈금/단위 표기, 0부터 시작하는 일관된 스케일.
- 그래프 유형: 막대 / 선 / 영역. 그리드: 끔 / 가로 / 가로+세로.
- +/− X축 기간 확대·축소(7/14/30/90/365일), ‹/› 이전·다음 기간 이동.
- 구간을 터치하면 날짜와 정확한 집계값 표시. 키보드 Enter/Space 지원.
- 실제 0은 빈 원(○), 기록 없음은 회색 짧은 표시(—)로 구분.
- 퀘스트 예정일 미수행 = 0회, 예정하지 않은 날 = 예정 없음, 수치 달성량 미입력 = 기록 없음.
- 조회 기간의 성과 카드와 그래프 표시 기간은 분리되어 있으며, 차트 제목에 표시 범위와 일/주/월 집계 방식 안내.
- 그래프 설정은 트레이너별 analyticsView.chartOptions로 저장되고 JSON 저장/복원에 포함.
- 서버/유료 API나 추가 외부 라이브러리 불필요.

[검증]
- JS 구문 검사 및 Chromium 브라우저 320/390/800px 그래프 표시, 라이트/다크 테마 확인.
- 그래프 유형, 그리드, 확대·축소, 터치 상세, 이전 데이터 백업값 정리 확인.
- 기록 없음/실제 0 분리 및 그래프 가로 넘침 검사.
- 갤럭시 실기기 및 장기간 PWA 사용은 별도 확인 필요.

[적용]
1. 설정 탭에서 JSON 전체 Save 백업 후 안전한 장소에 보관합니다.
2. ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소 루트에 덮어씁니다.
3. 다른 manifest.webmanifest 와 icons/ 폴더는 삭제하지 않습니다.
4. 배포 후 화면 표시 버전 V1.7.59를 확인하고 기록 탭의 그래프를 검사합니다.
5. 캐시 때문에 예전 화면이 남으면 앱을 다시 열고 새로고침합니다.

PokéRoutine v1.7.58.1 — 성도지방 열림 기준 변경 (관리자 설정)

[업데이트]
- 관동 151종 + 성도 100종 = 총 251종, 251종 상식, 지역별 도감·통계·지도 기능 유지.
- 성도지방 열림 기준 기본값: 관동의 서로 다른 포켓몬 100종 수집 (기존 76종에서 변경).
- 설정 경로: 상단 ⚙️ 설정 → 🗺️ 도감 지역 열림 기준 · 관리자 설정.
- 관리자 비밀번호 확인 후 1~151종 정수로 변경 가능.
- 이 값은 관리자 공통 규칙이며 트레이너별 독립 수집 기록에 적용.
- 한 번 열린 성도지방은 기준을 높여도 잠기지 않음. 수집 기록, 기존 훈장도 유지.
- 관동 탐험가 훈장은 성도지방 열림과 연결되고 설정값/기존 열림 상태를 반영.
- v1.7.58에서 76종 이상 수집해 성도가 이미 열려 있던 트레이너는 업데이트 후에도 이용 가능.
- 새 트레이너 / 1.7.57 이하에서 직접 업그레이드한 트레이너에는 기본 100종 기준 적용.
- 관리자 공통 규칙과 트레이너별 영구 열림 상태를 JSON 전체 백업·복원에 포함.
- 서비스워커 캐시 이름 갱신.
