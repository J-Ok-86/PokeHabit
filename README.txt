PokéRoutine v1.7.72 — 매일 첫 방문 랜덤 보상

• 기존 600P 첫 시작 선물은 유지합니다. 수령한 다음 날부터 하루에 한 번 랜덤 상자를 열 수 있습니다.
• 하루 한 번 직접 수령합니다. 보상 확률: 포인트 50~100P 45%, 트레이너 XP 40~80 30%, 대표 포켓몬 XP 30~60 15%, FEVER 티켓 60분 P·XP +20% 8%, 대박 200P+100XP 2%.
• 대표 포켓몬이 없거나 최대 레벨일 경우 해당 XP를 트레이너 XP로 지급합니다. 트레이너 레벨업 보상/무료 선물 규칙, 기존 포켓몬 성장과 진화 규칙을 유지합니다.
• FEVER 티켓은 받은 당일 직접 활성화하며 사용하지 않으면 자정에 소멸합니다. 활성화 후 60분이 지나거나 자정이 되면 종료됩니다. 정규 FEVER +10%와 겹치면 +20%만 적용합니다.
• 일일 보상 수령 이력, 티켓 활성화 내역을 계정별 JSON 백업/복원에 포함합니다. 자동 저장이 꺼져 있으면 일일 보상 지급/티켓 시작을 막아 재수령 오류를 방지합니다.
• 오늘 탭에 작고 명확한 행운 상자 영역을 추가하고, 예전에 받은 첫 선물은 상태 안내 한 줄로 축소했습니다.

적용: 먼저 JSON 백업을 저장한 뒤 ZIP 내 index.html, moves.html, sw.js를 같은 경로에 덮어쓰고 V1.7.72를 확인하세요.
