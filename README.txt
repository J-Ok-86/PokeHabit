PokéRoutine v1.7.24 · 도감↔훈련 이동 및 기술 시연 위치 개선

적용 방법: ZIP을 풀고 index.html, moves.html, sw.js 파일을 GitHub 저장소 루트에 덮어쓰세요.
README.txt는 안내용이며 올리지 않아도 됩니다.

수정 내용
1. 도감의 「이 포켓몬 트레이닝」 클릭 시 해당 개체를 선택한 채 훈련 탭의 실제 실행 버튼까지 자동 스크롤합니다.
   같은 종류가 여러 마리라도 도감에서 선택했던 개체를 우선합니다.
2. 훈련 탭에서 포켓몬 선택 시 훈련 시작/경험치 직접 지정 버튼이 보이는 위치까지 스크롤합니다.
   화면 크기와 하단 고정 메뉴 공간을 고려하며 선택한 트레이닝 카드가 짧게 강조됩니다.
3. 도감의 「기술 사용 보기」를 누르면 해당 기술 바로 아래에서 시연이 펼쳐집니다.
   기술을 바꾸면 이전 시연을 접고 새 시연을 표시합니다. 사용 가능한 기술에만 버튼이 나타납니다.
   최초 기술 획득 시 자동 시연은 기존 팝업 유지. 원래 스킨 및 「다시 재생」/「도감으로 돌아가기」 버튼 유지.
4. 서비스워커 캐시 버전을 v1724로 갱신합니다.

유지 사항: 기존 포켓몬 기술 모션, 포인트·XP, 도감, 계정 데이터, JSON Save/Load 구조는 변경하지 않았습니다.
