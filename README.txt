PokéRoutine v1.7.76 — 타임로그 정밀 UI 개선

배포 절차
1. 각 사용자 계정에서 JSON 백업 파일을 저장하세요.
2. ZIP 안의 index.html, moves.html, sw.js를 GitHub Pages 저장소의 같은 경로에 덮어쓰세요.
3. 배포 완료 후 페이지를 재로딩하세요. PWA라면 완전히 종료 후 재실행하세요.

개선 내용
- 큰 체크 버튼과 과장된 그림자를 제거하고, 초록 체크 원 / 노랑 메모 사각형을 14px 벡터 아이콘으로 통일했습니다.
- 시간축 및 범례가 동일한 SVG 기호를 공유하므로 서로 다르게 보이는 문제가 없습니다.
- 00·06·12·18·24 눈금과 완료·메모 마커가 동일한 위치 공식을 사용합니다.
- 전체 가로폭 사용을 유지하면서 2개 레인을 31px의 낮고 차분한 스타일로 정리했습니다.
- 가까운 시각은 자동 묶음 처리하며 작은 숫자 배지를 붙이고, 누르면 개별 시각·기록을 확인할 수 있습니다.
- 아이콘은 작지만 터치 영역은 약 27~34px이며 화면 크기에 따라 중복 표시를 자동 조절합니다.
- 기록 저장, 백업, 완료 보상, 기타 기존 기능은 변경하지 않았습니다.

시작·종료·소요 시간을 별도 측정하지 않으며 기존의 완료 시각만 이용합니다.
GitHub 배포는 자동으로 수행되지 않습니다.
