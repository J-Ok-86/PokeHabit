PokéRoutine v1.7.98 — 하루 타임로그 겹침 기록 확대·좌우 이동

기준: v1.7.97 (최신 퀘스트별 전체 수행 기록 포함)

새 동작
- 달력에서 날짜 선택 → 하루 타임로그의 겹친 기록 숫자 마커 터치 → 선택 시각 중심 확대 패널 열림.
- 원본 24시간 시간축은 항상 위에 보존. 확대 범위는 위쪽 원본 시간축에도 음영으로 표시.
- 확대 화면에서 손가락으로 좌우 스와이프(브라우저의 기본 관성 스크롤), PC에서는 마우스로 빈 곳을 잡아 드래그하여 다른 시간대 탐색.
- ＋ 확대 / − 축소는 15분, 30분, 60분, 90분, 180분, 360분, 720분, 1440분 범위. 기본 90분, 묶인 기록이 넓게 퍼진 경우 더 넓은 범위로 시작.
- ↩ 전체 보기 버튼으로 언제든 확대 패널을 닫고 전체 24시간 보기만 남길 수 있음.
- 확대 중 같은 시각·인접 시각의 기록은 겹치지 않도록 여러 줄에 배치. 기록 마커 터치 → 기존 퀘스트·순간 기록·생활 기록 상세 항목 펼침.
- 확대 화면은 원본 기록을 다시 저장하거나 복제하지 않음. 기존 퀘스트 상세·생활 이벤트 편집·계정/백업 기능 유지.
- 화면 폭 320px, 390px 시험과 문법 검사 통과. 화면 회전과 컨테이너 폭 변경 시 패널 재계산 기능 적용.

업데이트
1. 앱의 설정에서 사용 중인 데이터를 JSON 백업.
2. ZIP 안 index.html, moves.html, sw.js 세 파일을 GitHub Pages 저장소의 기존 파일에 덮어쓰기.
3. 배포 반영 후 설치형 PWA를 완전히 종료하고 재실행.

참고
- 이 ZIP은 GitHub에 자동 배포하지 않은 업데이트 패키지입니다.
- 320px/390px PC 헤드리스 Chromium 시뮬레이션에서 겹침 터치, 좌우 시간 이동, 확대, 상세 진입, 전체 보기 복귀 확인. 태블릿 실기기·모바일 PWA 제스처 실측은 아직 수행하지 못했습니다.
