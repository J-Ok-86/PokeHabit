PokeHabit / PokeRoutine v1.7.109 — 퀘스트별 스마트 기록 템플릿 + 독서 목록 + 상세 분석

기준: v1.7.106. 기존 퀘스트·완료 이력·기록·보상·타임로그·생활리듬 구조를 유지합니다.

v1.7.109 추가 개선
- 기존 독서 완료 기록의 메모에서 책 제목·시작/종료 쪽수를 읽기 전용으로 인식합니다. 여러 줄에 여러 책을 쓴 기록도 개별 책으로 분리해 표시합니다.
- 인식한 책 제목은 독서 입력창의 자동완성 후보에 포함됩니다. 최근 기록에 등장한 책 순서로 노출됩니다.
- 전체 독서 목록의 별도 「기존 메모에서 발견한 책 (추정)」 섹션에서 인식한 책을 확인하고, 원하는 책만 직접 등록할 수 있습니다. 등록 시 전체 쪽수와 완독 여부는 수동 입력합니다.
- 책별 분석에 과거 날짜와 읽은 쪽수 범위 (추정)를 추가합니다. 등록된 책에 대해 구간 중복 제거 진도율은 (추정 포함)으로 표시합니다.
- 과거 달성량 원본 및 메모는 변경하거나 구조화 저장하지 않습니다. 기존 숫자 합계는 (추정) 별도 집계를 유지하고, 인식한 구간을 합산해 이중 계산하지 않습니다.
- 과거 기록의 「완독」 텍스트는 「완독 언급 (미확정)」으로만 표시하며 자동으로 완독 체크하지 않습니다.
- 메모가 비어 있거나 문장에 구간을 구별할 수 없는 경우 임의의 책을 생성하지 않습니다.

v1.7.108 추가 개선
- 퀘스트 추가/수정 시 템플릿을 선택하면 아래에 입력 양식/자동 계산/상세 분석 예시를 실시간 미리보기로 표시합니다. 예시는 실제 저장 데이터가 아닙니다.
- 오늘 이미 작성 중인 임시 기록은 퀘스트 템플릿을 바꾸면 새로운 템플릿 입력창으로 표시합니다. 완료된 과거 기록은 원래 템플릿을 유지합니다.
- 이전 임시 기록의 수치/단위/메모는 삭제하지 않습니다. 새 템플릿에서 입력한 항목이 있으면 옛 수치는 별도 보관(합계 미포함)합니다. 새 템플릿을 비워 둔 채 저장하면 옛 기록을 유지합니다.
- 이전 임시값과 새 입력값을 자동 합산하지 않아 중복 계산을 방지합니다.

기존 v1.7.107 기능
1. 관리자 인증 후 퀘스트 수정 → '퀘스트별 상세 템플릿'에서 선택
   - 기본 수치/메모, 독서, 반복 운동, 근력 운동, 학습, 시간, 거리, 수량
   - 기존 퀘스트는 기본 입력 방식 유지; 템플릿은 개별 퀘스트에만 적용
2. 달성 기록/완료 전 중간 저장에서 여러 항목 입력, 항목별 합계/전체 자동 계산
3. 독서: 여러 책 입력, 읽는 중인 책 제목 자동완성, 신규 책 전체 페이지 수 1회 입력
   - 기록탭 '퀘스트별 성장 분석' → 전체 독서 목록; 여기서 완독 수동 체크·책 정보 수정
   - 전체 책 목록은 퀘스트별이 아닌 현재 사용자 계정별로 관리
   - 책별 진행률은 기록된 고유 페이지 구간을 합쳐 계산(재독 중복 제외)
4. 운동: 운동 종목/세트 반복 추가, 횟수 입력 시 실제 입력 시각 자동 기록
   - 하루 중 수시로 중간 저장한 뒤 이어쓰기, 기존 세트 시각 유지
5. 템플릿별 상세 분석: 책/항목별 누적량·추세, 완독·진도, 세트별 시각, 정답률, 운동 볼륨, 페이스 등
6. 기존 숫자 기록: 원본 유지; 해당 단위의 과거 숫자를 '기존 기록 (추정)'으로 별도 표시
   - 독서는 메모의 명시적 제목·구간만 (추정)으로 별도 표시, 운동 종목이나 세트 시간은 임의 추정하지 않음
7. JSON Save/Load 및 완료 전 초안 보존을 위해 structured 데이터, recordLibrary를 보존하도록 검증 코드 확장
   - 완료 후 기록 수정은 보상을 다시 지급하지 않음
