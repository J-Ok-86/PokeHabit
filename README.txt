PokeHabit / PokeRoutine v1.7.107 — 퀘스트별 스마트 기록 템플릿 + 독서 목록 + 상세 분석

기준: v1.7.106. 기존 퀘스트·완료 이력·기록·보상·타임로그·생활리듬 구조를 유지합니다.

새 기능
1. 관리자 인증 후 퀘스트 수정 → '퀘스트별 상세 템플릿'에서 선택
   - 기본 수치/메모, 독서, 반복 운동, 근력 운동, 학습, 시간, 거리, 수량
   - 기존 퀘스트는 기본 입력 방식 유지; 템플릿은 개별 퀘스트에만 적용
2. 달성 기록/완료 전 중간 저장에서 여러 항목 입력, 항목별 합계/전체 자동 계산
3. 독서: 여러 책 입력, 읽는 중인 책 제목 자동완성, 신규 책 전체 페이지 수 1회 입력
   - 기록탭 '퀘스트별 성장 분석' → 전체 독서 목록; 여기서 완독 수동 체크·책 정보 수정
   - 전체 책 목록은 퀘스트별이 아닌 현재 사용자 계정별로 관리
   - 책별 진행률은 기록된 고유 페이지 구간을 합쳐 계산(재독 중복 제외)
4. 운동: 운동 종목/세트 반복 추가, 횟수 입력 시 실제 입력 시각 자동 기록
   - 하루 중 수시로 중간 저장한 뒤 이어쓰기, 기존 세트 시각 유지
5. 템플릿별 상세 분석: 책/항목별 누적량·추세, 완독·진도, 세트별 시각, 정답률, 운동 볼륨, 페이스 등
6. 기존 숫자 기록: 원본 유지; 해당 단위의 과거 숫자를 '기존 기록 (추정)'으로 별도 표시
   - 추정 기록은 책/운동 종목에 임의 배정하지 않고 구조화 기록 그래프와 합산하지 않음
7. JSON Save/Load 및 완료 전 초안 보존을 위해 structured 데이터, recordLibrary를 보존하도록 검증 코드 확장
   - 완료 후 기록 수정은 보상을 다시 지급하지 않음
