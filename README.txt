PokéRoutine v1.7.27 · 컴팩트 훈장 전시대 및 퀘스트 보상 훈장 부스트

GitHub Pages 업데이트: ZIP 압축 해제 후 index.html, moves.html, sw.js를 기존 PokeHabit 저장소 같은 위치에 덮어쓰기.
기존 설정/기록 보존을 위해 업데이트 전에 앱에서 전체 JSON Save 백업을 권장합니다.

이번 버전
- 오늘 탭: 일반 6계열 + 특별 4종, 각 훈장마다 고정 전시 슬롯. 세로 여백 최소화.
- 잠긴 훈장은 모두 무채색/흑백 실루엣 및 잠금 마크로 표시. 누르면 달성 조건과 진행률 표시.
- 일반 5등급: 브론즈, 실버, 골드, 플래티넘, 마스터.
- 신규 일반 훈장/승급: 계정별 48시간 +5/+8/+12/+15/+20% 포인트와 XP. 다른 일반 훈장으로 갱신 시 최고 등급 적용 및 48시간 초기화.
- 특별 훈장 4종: +2/+3/+4/+5% 포인트/XP 영구 중첩 (최대 +15% 영구).
- 퀘스트 완료: 기존 시간/연속/추천/Fever 단계 이후에 훈장 부스트 단계 추가, 포인트/경험치 지급과 이력 동일 계산. 획득한 새 훈장 효과는 다음 퀘스트부터 적용.
- 기존 달성 기록은 소급 인정하되, 과거 달성에 대한 48시간 보너스는 소급 발동하지 않음.
- 훈장 획득/등급/48시간 종료 시각은 사용자별 JSON 데이터에 포함. 이전 버전 JSON 로드는 기존 형식 유지.
- 기존 포켓몬 훈련 화면 위치, 도감 기술 시연, 1~4열/자동 보기는 기존대로 유지.

주의: 별도 GitHub Pages 자동 배포는 수행되지 않았습니다.
