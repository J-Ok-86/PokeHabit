개선 사항
- 기존 시간축 구조 유지, 24시간 축에 가로폭 전체 사용 (기존 왼쪽 라벨용 66px 삭제)
- 퀘스트 완료 = 초록 원 ✓ / 순간 기록 = 노란 사각 ✎ (별도 레인)
- 아이콘끼리 겹치는 시간대는 개별 점을 숨기는 대신 건수 표시 묶음으로 합침
- 묶음 터치 시 개별 시각/이름 목록 표시, 선택 시 해당 상세 이력 이동
- 화면 폭 변경 때 마커 충돌 상태 자동 재배치
- 기존 기록 저장, 보상 계산, 단일 완료 시각 자동 기록 등 기능 유지

주의
- 시작/종료/소요 시간은 추적하지 않습니다. 기존 시각 없는 과거 기록은 시간축에 표시하지 않습니다.
- 배포는 자동으로 되지 않습니다.
