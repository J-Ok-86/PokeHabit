PokéRoutine V1.7.65 — 오늘 탭 퀘스트별 누적 수행률 표시 및 정렬

변경 사항:
- 오늘의 모든 퀘스트 보기(격자/리스트/간단/한줄)에 누적 수행률%와 완료/전체 예정 수 표시
- 수행률 낮은 순 / 높은 순 정렬 추가 (기존 정렬 유지)
- 매일/요일별은 생성 이후 오늘까지 실제 예정일 기준. 과거 날짜를 알 수 없으면 첫 수행 기록부터 계산
- 일회성/예약/이벤트는 검증된 일정 기준으로 집계, 미확인 분모는 0
- 기존 데이터 및 보상 계산·포켓몬 기능 유지

설치: 기존 JSON 전체 백업 후 index.html, moves.html, sw.js 를 GitHub Pages 저장소 루트에 덮어쓰기.

주의: 이 ZIP은 실제 갤럭시 설치형 PWA에서는 검증되지 않았습니다.
