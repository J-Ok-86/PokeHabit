PokéRoutine V1.7.70 — 야생 대결 연출 강화·포켓볼 마무리

V1.7.69를 기반으로 한 GitHub Pages 업데이트입니다.

주요 변경 사항
1. 야생 포켓몬 특별 대결의 흐름을 자연스럽게 변경했습니다. 이제 야생 포켓몬이 먼저 공격하고, 그 다음 대표 포켓몬이 반격합니다.
2. 대결 장면에 맞춰 공격·방어·타격·헤롱헤롱·도주 상태를 시각적으로 표시합니다.
3. 대결에서 우세를 잡으면 상대 포켓몬이 헤롱헤롱 상태가 되고, 그 다음 포켓볼을 던집니다.
4. 대결 승리 후에는 기존 포켓볼 포획률에 +20%p를 적용하되 99%를 넘지 않습니다. 예: 기본 25% → 45%, 기본 82% → 99%. 대결 승리와 포획 성공은 서로 다른 판정입니다.
5. 대결에서 패배하면 대표 포켓몬이 헤롱거리고 야생 포켓몬이 도망가는 연출로 끝납니다.
6. 대결 모달에 단계별 설명 문구를 추가해 현재 무엇이 일어나는지 바로 이해할 수 있게 했습니다.
7. 기존 지역/도감/퀘스트/달성 기록과 JSON 백업·복원 형식은 유지하며, 대결 중단 후 이어보기용 데이터도 함께 보존합니다.

적용 방법
1. 현재 앱에서 JSON 전체 백업을 만든 뒤 파일을 따로 보관합니다.
2. 이 ZIP의 index.html, moves.html, sw.js를 GitHub Pages 저장소의 동일한 위치에 덮어씁니다.
3. 배포가 끝나면 앱을 다시 열어 V1.7.70 버전을 확인합니다. PWA 캐시가 남으면 앱을 완전히 종료 후 다시 실행합니다.

검증
- JavaScript 구문·ZIP 무결성
- 야생 선제공격 → 대표 포켓몬 반격 → 승패 분기 흐름
- 대결 승리 후 포켓볼 단계 분리 및 +20%p(상한 99%) 확률 적용, 성공/실패 결과 분기
- 대결 패배 시 대표 포켓몬 헤롱거림과 야생 포켓몬 도주 연출
- 기존 도감/중복 수량/진화/기록 기능 회귀 점검

실제 갤럭시 PWA 실기기 및 장기간 사용 환경에서는 추가 검증이 필요합니다.
